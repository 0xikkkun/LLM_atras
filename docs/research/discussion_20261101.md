# LLM Atlas：実験・ゼミのフィードバックと次の研究方針

更新日：2026-11-01。研究名の表記は **LLM Atlas**（旧表記 Atras）。既存リポジトリ名・Pythonパッケージ名・CLI名は互換性のため現状を維持する。

この文書は2026年10月の100モデル実験と、その後の議論を整理したもの。**実験済みの観察、評価の提案、未実装の手法を区別する。新しい実験を実施したという報告ではない。**

## 1. 研究の枠組みと目的

共通文章を各LLMに入力し、モデル間距離関数 → 距離行列 → 次元削減 → 地図の評価、という流れを取る。距離関数、次元削減、評価方法を別々に検討する。

目的例は、出力分布の近さ、内部構造の近さ、蒸留の教師選択やモデルマージ後の性質の予測。地図が見やすいこと、同系列が集まること、能力や応答方針が似ていることは同一ではない。「どの性質について近い地図が必要か」を先に定める。

## 2. 実験済みの設定と比較の範囲

- 15系列・100モデル、15分野×20件の共通英語文章、計300件。
- 全モデルに同じ文字列を入力し、特殊トークンを含め最大512トークン以内の共通接頭部を使用。
- 75モデルはFP16、25モデルは数値安定化のためFP32。個別設定は実験記録参照。
- グラフ用文章表現ηは、最終attentionのValueを最後のトークンからのattention重みで平均したもの。PCAで16次元にする。
- Euclideanのunion kNN（k=20）で接続先を共通にし、Euclidean／Fisherで辺長を変更する。Fisher計量は局所の正則化逆共分散に基づく。**FisherでkNN接続先を選び直す実験ではない。**
- グラフのノードは文章、モデル地図の点はLLM。各グラフの最短路距離や拡散特徴などを比較してモデル間距離を作る。
- ゼミでの主比較は、グラフ12条件（2計量×6比較法）＋Shimodaira Q clipped＋Hidden CKAの14条件。保存済みの全実験には他の参照条件もある。
- Shimodaira法はOyamaほか（ACL 2025）の共通文章上の手法追試。原論文のモデル数・文章数を完全再現したものではない。Qは二重中心化した対数尤度座標。
- Hidden CKAは最終層・最終トークン表現を使う。ηで説明するCKAの数式とは、入力特徴を置き換える点を区別する。
- MDSの評価値は2D metric MDSの10実行平均。Viewerの表示座標はseed 0で、3D表示中も追加した評価欄は2Dの集計値を表示する。

詳細：[100モデルプロトコル](../../experiments/100models/PROTOCOL.md)。公開Viewer：<https://llm-atlas-100.cozy-grebe-5879.chatgpt.site/>。

## 3. 既存結果から分かったこと

- 文章グラフの最短路近傍10件の同分野割合は、100モデル平均でEuclidean 13.58%、Fisher 16.01%。局所的なカテゴリ対応の改善であり、カテゴリ全体の明確な分離やLLM地図の有用性の証明ではない。
- 正規化Frobeniusでは、Euclidean→Fisherで同系列率88%→85%、Stress 0.311→0.257、距離順位相関0.766→0.828。系列の再現と2次元化の忠実度は一致しない。
- Euclidean RankとHidden CKAは最近傍同系列率90%。一方、Fisher NetLSDは37%だがStressは0.028。描きやすいことだけで距離を選べない。
- 300文章から240文章を抽出しグラフを再構築する20回の評価で、元のモデル間距離との順位相関はShimodaira Q clipped 0.9987±0.0010、Euclidean正規化Frobenius 0.9946±0.0013、Fisher正規化Frobenius 0.9909±0.0033。PCA・局所計量を固定した部分集合評価であり、別コーパスへのロバスト性とは区別する。

## 4. グラフ比較法で何を捉えるか

| 方法 | 比較する対象・仮説 |
|---|---|
| 非正規化Frobenius | 同じ文章対の距離の値。関係構造に加え、文章表現の広がり・距離スケールを反映する可能性 |
| 正規化Frobenius | 全体スケールを除いた文章間距離配置 |
| Rank | 全文章対の距離の順位。各文章から見た個別順位ではない |
| kNN overlap | 同じ文章について近傍に入る文章の顔ぶれ |
| NetLSD | ノード対応を使わない、グラフ全体の拡散・接続形状 |
| Gromov–Wasserstein（近似） | ノード対応を探索して比較する内部距離構造 |

これらの設計上の意味から、能力・学習データ・誤り方との対応を直ちに断定できない。既知の変換を加える対照で設計を検証し、未使用文章で汎化を確認する。グラフ構築とグラフ比較の両方に工夫の余地がある。

CKAは中心化Gram行列Kを正規化したときの距離 `||K_i/||K_i||F - K_j/||K_j||F||F = sqrt(2(1-CKA))` を使用。曲率ベクトルなども含め、特徴上の距離が0でもLLMや元グラフの同一性は保証しない。

## 5. 発表後のフィードバック：評価を深める

### 5.1 コーパス変更へのロバスト性【次の実験案】

出典・分野・文体を変えてモデル間距離を再計算し、変更前後の距離順位相関、k近傍一致率、クラスタリングの安定性を評価する。文章数・長さなどをそろえ、再抽出の反復と変動幅を報告する。

- モデル集合とID順を固定する。
- まず同じ分野構成で別文章を使う。次に分野構成そのものを変える。
- PCA・計量も各コーパスから再計算する主評価と、固定する対照を区別する。
- コーパスごとに文章が異なっても、比較対象は同じモデル対の距離行列なので比較できる。
- 数学など特定分野の地図を目的とする場合、分野変更による移動は望ましい可能性もある。すべての変化を失敗扱いにしない。

### 5.2 モデル系列のまとまりとクラスタの一致【評価追加案】

1. **系列シルエット係数**：次元削減前の距離行列と既知の系列ラベルを使用。同系列内距離の平均a、最も近い別系列への平均距離bから `s=(b-a)/max(a,b)` を計算する。既存CSVにも系列シルエット列があり、まずその定義と数値を監査して再利用する。
2. **系列とクラスタの一致度**：系列ラベルを使わず距離行列からクラスタリングし、系列とのARI・AMIを計算する。シルエットだけではクラスタと系列の一致は測れない。
3. 距離行列を直接扱えるaverage／complete linkageなどから始める。主比較を系列数15で固定する案と、クラスタ数を変える感度分析を区別する。ラベルで最良設定を選び、その同じラベルでの評価を唯一の結果にしない。
4. 100モデル全体の平均だけでなく、系列別と系列を等重みとした要約も報告する（系列サイズが不均衡）。
5. 同じ指標を2D座標でも計算し、距離関数と次元削減の影響を切り分ける。

シルエット、ARI、AMIは異なる評価であり、「精度」という単一の値にまとめない。[公式指標解説](https://scikit-learn.org/stable/modules/clustering.html)

### 5.3 その他の評価候補【議論した案】

- k近傍保存率、Trustworthiness、Continuity：元のモデル間距離から地図への局所構造の保存。
- 正誤・誤答パターン、分野別能力、拒否・迎合・不確実性表明：未使用問題上の機能的類似性。
- 蒸留教師の選択による性能改善、マージ後の性能予測誤差：実用上の有用性。

直近の優先フィードバックはコーパスロバスト性と系列／クラスタ評価。能力・応答方針は将来候補で、実施を決めた実験とは区別する。

## 6. 新しい距離案：Sobolev–Ricci曲率ベクトル【未実装・未評価】

### 6.1 使用する先行研究

Iwasaki, Le, Hino (2026), **Sobolev–Ricci Curvature**。

- 論文：<https://arxiv.org/abs/2603.12652>
- 実装：<https://github.com/ISMHinoLab/Geometric_perspectives_on_graph-based_learning_algorithms/tree/main/SobolevRicciCurvature>
- 計算コード：`community_detection/src/curvature.py`

SRCは近傍確率分布のSobolev輸送を用い、根付き木の構造上で効率的に計算する辺曲率。定義は `κ_SRC(a,b)=1-S_p(μ_a,μ_b)/D_p(a,b)`。分母D_pも同じSobolev幾何で定義するため、任意に元の辺長で代用しない。一般グラフでOllivier–Ricci曲率そのものと同一ではない。コードはSPT・MSTなどと辺長属性`length`を扱う。

### 6.2 我々が追加するモデル比較の構成案

1. 保存済みのEuclidean／Fisher文章グラフG_iで辺のSRCを計測。
2. 各ノードaに接続する辺のSRCを平均し、ノード特徴 `c_i(a)=mean_{b in N_i(a)} κ_i(a,b)` を定義する。
3. 共通文章ID順で `c_i=(c_i(1),...,c_i(n))` を並べる。
4. `d_curv(i,j)=sqrt(mean_a (c_i(a)-c_j(a))^2)` をモデル間距離とする。
5. 距離行列、2D MDS、系列評価、コーパス変更評価へ接続する。

ノードへの平均集約とLLM間距離は**我々の提案する構成案**であり、SRC論文の実証済み成果ではない。曲率特徴が一致しても元グラフの同一性は保証できない。

### 6.3 実装前に固定する項目と確認事項

- 初期案：p=1、SPT方式、元グラフの曲率を一回計算。Ricci flowによる反復変形やpruningはまず行わない。
- 近傍分布、自己点に残す確率α、木の方式・根・乱数を記録する。αは感度を調べて設定する。
- 根に依存するため、全モデル共通の文章IDを根として複数条件を比較し、根選択による距離変動を確認する。平均化はその後の候補。
- Euclidean／Fisherの違いを評価するには辺長を計算に渡す必要がある。現状は接続先が共通なので、無重みの接続だけでは両条件を区別できない。
- 正の辺長、非連結、重複文章・ゼロ辺長、非有限値の処理を検証する。
- 平均集約で失われる情報を調べる候補として分散・分位点や辺曲率を使った比較もあるが、主設定を増やしすぎない。
- 共通文章順を保ち、曲率値でソートしてから引き算しない。コーパスが異なる場合は、各コーパス内で作ったモデル間距離行列どうしを比較する。
- 著者実装のcommit・利用条件を確認して固定し、木上の検証例や小規模グラフで照合してから100モデルに適用する。

## 7. 実行順の案

1. 保存済み14条件の系列シルエットを監査し、階層クラスタリングのARI・AMIを追加。
2. コーパス変更実験の入力・反復数・条件を固定して実行。
3. SRCの小規模検証、根依存性・辺長の挙動を確認。
4. SRC曲率ベクトル距離を100モデルに適用し、既存14条件と同じ評価で比較。
5. 結果をViewerへ追加する。未実施の評価値を公開表示しない。
